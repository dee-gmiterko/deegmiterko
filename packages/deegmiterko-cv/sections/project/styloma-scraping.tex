\cvitem{Scraping}{
  Custom tooling that can be composed together to match the best approach for particular retailer, choosing:
  \begin{itemize}
    \item Access: Fetch, REST, Pupeteer, GraphQl, External scrapers,\ldots
    \item Parsing: HTML, JSON, XML, Dedicated known platforms like Shopify,\ldots
    \item Mapping of retailer taxonomies to our shared ones,
    \item Data quality rules tracking.
  \end{itemize}
}
